## Как получен снимок

- База выгружена SQL-запросами через Notion MCP 22.11.2026: все 468 строк, все поля. Тела страниц-строк не выгружались: у почти всех строк они пустые, весь текст в полях.
- Страницы выгружены инструментом fetch в Notion-flavored Markdown. Ссылки `app.notion.com/p/...` — идентификаторы частного пространства, открыть их без доступа нельзя; они нужны, чтобы ссылаться на конкретную строку в отчёте.
- Удалено перед публикацией: личные ссылки Sovendus и `moj.t-mobile.pl` (заменены на `[личная-ссылка-удалена]`), сохранённые HTML-страницы магазинов (769 МБ), скрипты и журналы доступа к телефону.
- С этой же страницей «По 2 варианта» параллельно работала другая сессия; в выгрузке — её состояние на момент fetch.
