## Shop promotions (summary of shop-promos.json)

### Sportano

**BLACKDEALS** ([regulamin PDF](https://sportano.pl/uploads/documents/pl/regulations/campaigns/regulamin_promocji_blackdeals_2026_pl.pdf)):
- Runs from 19.11.2026 00:00 to **24.11.2026 23:59**, online and in the Warsaw store.
- Applies only to products marked "Dodatkowe -X% z kodem BLACKDEALS" (the list is at sportano.pl/black-month-blind-deals). The percentage is set per product and shown on the product card. On neck gaiters it ranges from -5% to -57%.
- The code is entered in the basket field "Posiadam kod rabatowy". No login and no minimum basket.
- It cuts the current price, which is often already reduced.
- It does not combine with other promotions (§13).
- Check the "Najniższa cena" on every card: for many items the code price equals or exceeds the 30-day low.

**Newsletter code: 50 zł off orders over 499 zł.**
- The value and threshold come from the signup block on every sportano.pl page: "Odbierz 50 zł zniżki na zakupy* dołączając do newslettera — *na produkty o łącznej wartości powyżej 499 zł, promocje nie łączą się ze sobą".
- "Single use" and "logged-in users only" come only from the text the buyer received. They are not on the site.
- The newsletter regulamin (in force from 18.09.2026) does not describe the code at all. So no validity period is published, and there is no rule on whether the code works on already reduced prices. An older leaflet code of the same value (RABAT50, 26.09–31.12.2023, sportano.pl/regulaminpromocji) was limited to non-reduced items.
- How to get it: sign up with an e-mail address on sportano.pl, tick the consent box and click the activation link. The code arrives by e-mail, and you must be logged in to an account at checkout.
- The top banner on the site now advertises the APP code instead; the 50 zł line is commented out in the HTML. The footer signup block still shows 50 zł.

**Can the newsletter code replace BLACKDEALS?** Only as an alternative, not on top of it, because both texts say promotions do not combine. Whether the basket technically accepts two codes was not tested. Rule of thumb:
- If the basket is over 499 zł and the BLACKDEALS savings on marked items total less than 50 zł, use the newsletter code.
- Otherwise use BLACKDEALS. Note that BLACKDEALS ends 24.11 at 23:59, while the newsletter code has no published end date.

**APP** ([regulamin](https://sportano.pl/regulamin-promocji-app)): 40 zł off orders of at least 399 zł, Sportano mobile app only. One use per person, valid 4.09–31.12.2026, does not combine.

**Delivery**: Paczkomat or ORLEN Paczka 8.99, DPD Pickup or DPD courier 9.99, InPost courier 11.99. Free above 299 zł; InPost courier stays 9.99. The product JSON-LD lists 7.99, so confirm the cost in the basket. The only physical store is in Warsaw (Targówek), none in Katowice.
